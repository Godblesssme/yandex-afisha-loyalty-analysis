# Анализ лояльности пользователей Яндекс Афиши

## Описание проекта
Исследовательский анализ данных пользователей сервиса Яндекс Афиша для выявления факторов, влияющих на повторные покупки.

## Результаты
- 61.8% пользователей совершают повторные заказы
- 29.0% пользователей делают 5+ заказов
- Ключевой фактор: 2-3 билета в заказе (+12 п.п. к возврату)
